# 🌐 Root Branch

This branch contains the complete source code for WorkStudy and serves as the root directory for the website.

## 📁 Directory Structure

```txt
root/
├── index.html
├── proxy.html
├── Soundboard.html
├── chat.html
├── style.css
├── script.js
├── robots.txt
│
└── Games/
    ├── index.html
    ├── script.js
    ├── games.js
    │
    └── books/
        └── mc.html
```

## 🚀 Purpose

This branch contains the files used to run and deploy WorkStudy.

## 🌐 Main Pages

```txt
index.html        → Homepage
proxy.html        → Proxies
Soundboard.html   → Soundboard
chat.html         → Chat
Games/index.html  → Games
Games/books/mc.html → Eaglercraft
```

## 💾 Offline Use

1. Download `WorkStudy-Offline.zip`
2. Extract the ZIP
3. Open:

```txt
index.html
```

4. Enjoy WorkStudy offline.

## ⚠️ Important

- Keep all files in their original folders.
- Do not rename files unless all references are updated.
- The Games folder is required for games to function.
