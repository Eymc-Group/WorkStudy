ℹ️ How Account Proxies Work
When you log in to GD Webport, your password is hashed with SHA-1 and sent as a gjp2 parameter to boomlings.com/database/accounts/loginGJAccount19.php. Because browsers block direct cross-origin requests, the login goes through a Cloudflare Worker that relays it. A response of -1 means the proxy is alive but the credentials were wrong. A positive number means you're logged in.

ℹ️ How Game Proxies Work
Every game request (loading levels, scores, etc.) also goes through a Cloudflare Worker, because boomlings.com doesn't allow requests from browsers. The Worker receives the request, forwards it to boomlings.com, and returns the response. Primary workers are the same ones used for login. Fallback workers are community-hosted and kick in if the primaries are down.

ℹ️ How Direct Connection Works
This tests if boomlings.com itself is reachable — without any proxy. Browsers always block this request with a CORS error, so a fast failure (CORS) actually means the server is online. A timeout means boomlings.com is unreachable or completely down.
