# 🎮 WorkStudy

WorkStudy is a browser-based hub that combines games, utilities, account features, cloud saves, and other web tools into a single platform.

## ✨ Features

- 🎮 Games Library
- 🔍 Search & Discovery
- 💾 Cloud Saves
- 👤 User Accounts
- 🎨 Custom Themes
- ⚙️ Settings System
- 📱 Responsive Design
- 🚀 Fast Static Deployment
